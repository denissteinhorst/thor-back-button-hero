2.1.1 makes hold-to-swap work with IISU and Cocoon.

- **Hold-to-swap in IISU and Cocoon.** While IISU or Cocoon fills both screens, holding Back now uses the frontend's own screen swap, so the two screens trade places. In IISU it follows the "Screen swap" button set in IISU's settings; with IISU's swap turned off, you get a short message instead.
- **Apps that undo a swap are recognized.** If an app moves itself straight back after a swap, you get a message that it can't be swapped, and it isn't moved again on every hold.
- **A message when nothing can be swapped.** Hold-to-swap and "Switch active app" now say so instead of doing nothing silently, for example when the second screen isn't available.

**Updating keeps your customized bindings.**
