A hotfix for 1.4.0. Thanks to u/moosedude451 for the report that started it.

## Fixed
- **Auto-lock stays Auto-lock.** Opening bottom or top Recents switched AYN's Focus Mode to a fixed lock on the bottom screen, and you had to set it back to Auto-lock in AYN's settings every time. Recents now hands the controller back exactly as it was, Auto-lock included.
- **Swapping RetroArch no longer locks the controller focus.** 1.4.0 moved the controller focus along with RetroArch on every swap (experimental). That caused the lock and wasn't needed, so it's gone.
- **Bottom Recents shows above AYN's panel.** Recents could open completely hidden behind AYN's assistant panel on the bottom screen. The panel now behaves like any other window there: Recents covers it, closing Recents without picking anything brings it back, and opening an app parks it behind its own card. AYN's button always brings a parked panel back with one press, and closing its card closes the panel just like AYN's button does.

## Changed
- **Back Button Hero no longer moves apps or the controller on its own.** 1.4.0 moved the other app back after a swapped app was closed (for example Companion back below ES-DE). Apps now only change screens when you swap them, and the controller focus only changes when you ask for it.
